# 术语表

代码、文档和对话里统一用这里的叫法。代码里的命名用"英文"一列。

标"推断"的术语来自早期原型代码，含义尚未经用户确认。

| 术语 | 英文 | 含义 | 不要叫成 |
|---|---|---|---|
| 平台 | Platform | 整个系统；承载多个实例 | 系统（太泛） |
| 实例 | Instance | 一个独立的采集项目（租户）：自己的科目表、机构、用户授权、模板、填报，与其他实例隔离 | 租户（可在技术讨论中用）、环境（实例不是部署环境） |
| 机构 | Organization | 被要求填报数据的单位，属于一个实例。字段由实例定义，不绑定任何行业 | 门店、客户 |
| 机构分类 | Organization Dimension | 实例自定义的机构分类维度，例如区域、行业，取值可有层级 | 区域、行业（那是具体例子） |
| 用户 | User | 一个能登录的人，邮箱是平台内的唯一标识；可属于多个实例 | 账号 |
| 权限 | Permission | 系统里一个最小的可授权操作，代码中固定 | 功能点 |
| 角色 | Role | 权限的集合 | 用户组 |
| 授权 | Role Grant | (用户, 角色, 实例[, 机构]) 的一条记录；实例为空表示平台级 | 分配、指派（动作可以这么说） |
| 平台管理员 | Platform Admin | 持有平台级角色的人，管理实例，不自动拥有实例内数据权限 | 超级管理员 |
| 实例管理员 | Instance Admin | 管理本实例的科目表、机构、用户和授权 | 管理员（太泛） |
| 模板设计人 | Template Designer | 设计并发布模板的人 | 设计者、作者 |
| 填报人 | Data Submitter | 代表机构填写并提交数据的人 | 录入员、客户用户 |
| 机构管理者 | Organization Manager | 管理本机构用户的人（待确认，见 Q-016） | 机构管理员 |
| 科目表（推断） | COA | 一个实例里定义"收集什么"的主数据全体：计量单位、属性、分类组、分类、选项列表。全称为推断，见 Q-004 | 字典、基础数据 |
| 计量单位 | Unit of Measure (UoM) | 定义值的数据类型和校验规则，例如"百分比""金额" | 单位（容易与度量衡混淆） |
| 属性 | Attribute | 科目表中通常对应模板"列"的项，例如"期初" | 列、字段 |
| 分类组 | Category Group | 把分类分组的层级节点 | 类别组 |
| 分类 | Category | 科目表中通常对应模板"行"的项，例如"门诊收入"，可有父子层级 | 行、科目 |
| 选项列表 | Option List | 下拉类型单元格的取值集合，按实例维护 | 枚举、字典 |
| 数据点 | Data Point | 模板中一个录入位，由 (属性, 分类) 唯一确定 | 单元格（单元格是网格上的位置，数据点是它代表的含义） |
| 模板 | Template | 一份采集表单的定义：若干工作表，每个录入位绑定 (属性, 分类)，带公式和校验。来自一份 Excel | 报表、表格 |
| 工作表 | Worksheet | 模板里的一页，早期原型叫 Tab | 标签页 |
| 计算单元格 | Calculated Cell | 值由公式得出、填报人不能直接编辑的单元格 | 公式列 |
| 科目表快照 | COA Snapshot | 模板发布时固定下来的科目表项副本，保证历史口径不变 | 备份 |
| 财年 | Fiscal Year | 一个按日期界定的年度，例如 2026-27 | 年度 |
| 报告期 | Reporting Period | 财年内的一个期间，例如 Q1 | 季度（季度只是一个例子） |
| 发布 | Publish | 把模板发给选定机构：模板锁定，并为每个机构生成一份填报 | 下发、分发 |
| 停用 | Retire / Deactivate | 对象不再可被新使用，但历史保留。不同于删除 | 逻辑删除、禁用 |
| 填报 | Submission | 一个机构对一份已发布模板的一次填写任务及其数据 | 提交单、任务 |
| 提交 | Submit | 填报人把填报正式交出的动作，会生成提交快照 | 保存（保存只是草稿） |
| 提交快照 | Submission Snapshot | 每次提交时保存的不可变的数据副本 | 版本 |
| 撤回 | Withdraw | 截止日前把已提交的填报退回可编辑状态 | 取消提交 |
| 延期 | Extend | 实例管理员对某机构延长截止日 | 展期 |
| 重新打开 | Reopen | 实例管理员在截止后让某机构的填报可再编辑 | 解锁 |
| 工作表锁 | Worksheet Lock | 某填报的某工作表在同一时间只允许一人编辑 | 编辑锁（可以说） |
| 加载项 | Add-in | 在 Excel 里使用的模板设计工具，登录平台后拉取科目表 | 插件、宏 |
| 审计日志 | Audit Log | 只追加的变更记录：谁、何时、改了什么、旧值、新值 | 日志（日志是运行日志，审计日志是业务记录） |
| 留存 | Retention | 数据保留多久、到期怎么清理的规则 | 归档 |
| 早期原型 | Legacy | 从未上线的早期原型，只作需求参照 | 旧版本、V1 |
